# 1.3.1-forever

Keep each character's tracker layout independent when switching characters.

Changes are compared with [v1.3.0](https://github.com/eavidaze/wow-addon-per-hour/releases/tag/v1.3.0),
the previous published Forever release. The release title and tag are `v1.3.1`.

## Fixed

- Save tracker visibility, tracker positions and the minimap button position
  per character. Moving or hiding a panel on one character no longer changes
  another character's layout.

## Compatibility and limitations

- Targets WoW Forever 1.60.1, Interface `16001`.
- Previous account layouts are not imported. On the first login after updating,
  each character starts with hidden trackers and default panel and minimap
  positions. Show the desired trackers and arrange them again for each character.
- Existing saved sessions are preserved. Hourly/per-minute display preferences
  remain shared by the account, independently for XP, honor and reputation.
- Session continuity retains its existing 30-second played-time tolerance and
  depends on normal logout or UI reload to save to disk.

## Validation

- Automated: 1,086 simulation checks passed with Lua 5.1 through Python's
  `lupa.lua51` runner, covering independent character layouts, shared display
  rates, reload persistence, ignored account layouts and session preservation.
- Local package: `per-hour-1.3.1-forever.zip` checked for the `per-hour/` root,
  matching version and Interface, exact TOC/XML reference casing and excluded
  development files.
- In-game validation is pending. Confirm panel visibility, panel dragging,
