# 1.3.0-forever

Configure each tracker from a shared settings panel, choose hourly or per-minute
rates, and select the watched reputation without leaving the addon.

Changes are compared with [v1.2.1](https://github.com/eavidaze/wow-addon-per-hour/releases/tag/v1.2.1),
the previous published Forever release. The release title and tag are `v1.3.0`.

## Added

- Open **Per Hour Settings** by right-clicking the minimap clock or choosing
  **Settings** from any tracker's **Options** menu. Show or hide each tracker
  from the shared panel.
- Choose **Per hour** or **Per minute** independently for XP, honor and
  reputation. The saved choice updates the displayed rate immediately without
  changing session totals, duration or pause state.
- Select **Tracked faction** in the Reputation settings. The list includes
  known factions in collapsed and inactive groups, supports scrolling, and
  stays synchronized with the game's watched faction. **None** clears it;
  switching factions retains the existing reputation-session reset behavior.

## Changed

- Compact tracker titles use a centered native boxed header spanning the row
  with the same side insets as the footer. The restore icon aligns with the
  panel's top-left corner. The settings panel includes discreet addon branding.
- Minimap tooltips explain left-click, right-click and dragging. Tracker gear
  menus group **Reset**, **Settings** and **Announce** under **Options**.
- **Announce** shares one chat message led by the hourly average, followed by
  active duration and total gains, with a `[Per Hour]` prefix. Reputation also
  includes the tracked faction.
- The AddOns list displays **Per Hour** with a watch icon and a Statistics
  category. Tracking controls and labels share consistent gold styling.

## Fixed

- Restore saved panel positions after entering the world, avoiding clamping
  against temporary loading-screen dimensions.
- Exclude development documentation, tests and tooling from release packages.

## Compatibility and limitations

- Targets WoW Forever 1.60.1, Interface `16001`.
- Preserves the Honor Points currency-event fix published in v1.2.1.
- Existing visibility, positions and sessions remain supported. New display-rate
  preferences default to hourly. Both rates remain available in session tooltips.
- Session continuity still uses a 30-second played-time tolerance and depends
  on normal logout or UI reload to save to disk; missing progress cannot be recovered.

  selection, honor gains, session continuity, announcements and panel layout.
