# 1.1.0-forever

This release introduces automatic panel separation and improves the tracker
interface, with session details available in live hover tooltips.

Changes are compared with [v1.0.0](https://github.com/eavidaze/wow-addon-per-hour/releases/tag/v1.0.0),
the previous published Forever release, whose TOC version was `1.0.0-forever`.

## Added

- Automatic separation of visible tracker windows while dragging, reopening
  panels and restoring saved positions. The moved panel finds a free position
  without pushing the other panels.

## Changed

- Tracking controls use an activity diamond to make the existing state clearer:
  green while running, yellow when paused and gray before starting or after a reset.
- Tracker windows are narrower: 180 pixels instead of 200.
- Hover tooltips now organize details into **Session** (duration and total gained)
  and **Rates** (hourly and per-minute gains), with the tracking state and watched
  reputation faction when applicable.
- Tooltips update while open, reflect pause/resume and reset immediately, and
  continue to show full values when the main panel abbreviates large rates.
- The expandable details section and note button have been removed. The main
  tracking button uses the available space beside the gear menu.
- Panel titles are aligned to the left, and close and options controls have
  adjusted sizing and spacing.

## Compatibility

- Targets WoW Forever 1.60.1, Interface `16001`.
- Saved visibility, panel positions and minimap position remain supported.
  Overlapping saved panel positions are adjusted when restored or shown.
- Sessions still restart after a reload or login; paused time and gains remain excluded.

## Validation

- Automated: 229 simulation checks passed using the Lua 5.1 engine through
  Python's `lupa.lua51` runner.
- Local package: `per-hour-1.1.0-forever.zip` generated and checked for the
  `per-hour/` root, matching version and Interface, 22 files matching the source,
  16 TOC/XML load references with exact filename casing, and excluded development files.
- Full in-game validation remains pending, including tracking across pause/resume,
  watched-faction changes, and panel placement at the intended UI scale.
