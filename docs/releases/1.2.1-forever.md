# 1.2.1-forever

This hotfix restores Honor Points tracking in WoW Forever.

Changes are compared with [v1.2.0](https://github.com/eavidaze/wow-addon-per-hour/releases/tag/v1.2.0),
the previous published Forever release. The release title and tag are `v1.2.1`.

## Fixed

- Count Honor Points earned through currency update events for currency 1792.
  The previous tracker read honor-level experience, which can remain at zero
  while spendable Honor Points increase.
- Preserve earned totals when spending honor and count subsequent gains even
  when the remaining balance is below the session's starting balance.
- Exclude the existing balance, paused gains, events outside the world and
  gains received while session restoration is pending.

## Compatibility and limitations

- Targets WoW Forever 1.60.1, Interface `16001`.
- Previously missed awards cannot be recovered from the current honor balance.
- Session totals remain subject to the existing played-time continuity check.

## Validation

- Automated: 533 simulation checks passed with Lua 5.1 through Python's
  `lupa.lua51` runner, including an eight-point currency gain while `UnitHonor`
  remains zero, spending, pause/resume, hidden panels, immediate logout,
  invalid event payloads and saved-session continuity.
- Local package: `per-hour-1.2.1-forever.zip` generated and verified for matching
  version and Interface, the `per-hour/` root, exact TOC/XML filename casing
  and excluded development files.
- In game: the user confirmed Honor Points gains with the same event-based fix
  before this isolated backport. The packaged hotfix and additional spending,
  pause/resume and reload scenarios have not been separately validated in game.
