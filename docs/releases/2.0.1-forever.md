# 2.0.1-forever

Keep the Session window steady when switching tabs and simplify its title.

Changes are compared with [v2.0.0](https://github.com/eavidaze/wow-addon-per-hour/releases/tag/v2.0.0),
the previous published Forever release. The release title and tag are `v2.0.1`.

## Fixed

- Keep the window's width, height and scale unchanged when switching between
  Income, Expenses and Reputation. All tabs reserve the space needed by the
  largest table header, avoiding the resize and screen-fit flicker caused by
  their different header heights. Tab contents remain scrollable, and wrapped
  session metadata can still expand the window when necessary.

## Changed

- Rename the Session Details window to Session, for both current and archived
  sessions. Sessions > Current Session continues to open the same window.

## Compatibility and limitations

- Targets WoW Forever 1.60.1, Interface `16001`, with Lua 5.1.
- No data migration, settings migration or new reset is introduced. Sessions,
  history and preferences created in 2.0.0 keep their existing formats.

## Validation

- Automated: 1,433 simulation checks passed with actual Lua 5.1 through Python's
  `lupa.lua51` runner, including repeated tab switching without a window resize,
  unchanged width/height/scale, the new title, and existing capture/history checks.
- Local package: `per-hour-2.0.1-forever.zip` verified for its `per-hour/` root,
  matching TOC version and Interface, source contents, 49 exact-case nested
  TOC/XML load references, embedded libraries/licenses and excluded development
  files. All 60 packaged source files match the candidate.
- Native rendering and the absence of visible flicker still require in-game
  confirmation, including different UI scales, long session metadata, current
  and archived sessions, and scrolling all three tabs. Simulation checks are
  separate from in-game validation.
