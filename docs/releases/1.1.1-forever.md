# 1.1.1-forever

This patch prevents existing XP from being counted again after temporary drops
in player progress readings, such as during hearthstone travel or loading screens.

Changes are compared with [v1.1.0](https://github.com/eavidaze/wow-addon-per-hour/releases/tag/v1.1.0),
the previous published Forever release, whose TOC version was `1.1.0-forever`.

## Fixed

- Preserve the last valid XP snapshot when player progress is temporarily missing
  or XP falls without a level change, preventing inflated session totals and rates
  when the original values return.
- Ignore invalid XP requirements so incomplete readings do not corrupt the next
  level-up calculation.
- Exclude the README from local release ZIPs, matching the existing `pkgmeta.yaml`
  rules used by the publishing workflow.

## Compatibility

- Targets WoW Forever 1.60.1, Interface `16001`.
- Tracking controls, saved settings and session behavior remain unchanged.
- A full interface reload or login starts a new session; ordinary travel keeps
  the current session running.

## Validation

- Automated: 235 simulation checks passed using the Lua 5.1 engine through
  Python's `lupa.lua51` runner, including temporary XP drops, restored progress,
  real gains after travel and level-up calculations.
- Local package: `per-hour-1.1.1-forever.zip` generated and checked for the
  `per-hour/` root, matching version and Interface, 21 files matching the source,
  16 TOC/XML load references with exact filename casing, and excluded development files.
- In-game validation remains pending: repeat hearthstone travel and zone loading
  during an active XP session, then verify real XP gains, level-ups and pause/resume.
