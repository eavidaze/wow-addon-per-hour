# 2.0.0-forever

Per Hour's session revamp replaces separate trackers with one configurable
dashboard, a shared measurement period and saved results you can review and compare.

Changes are compared with [v1.6.1](https://github.com/eavidaze/wow-addon-per-hour/releases/tag/v1.6.1),
the previous published Forever release. The release title and tag are `v2.0.0`.

## Added

- Start, Pause, Resume and Finish one session for XP, Gold, honor and reputation
  together. Hiding the dashboard keeps capture running; Finish archives the result
  and waits for the next Start.
- Save named results in History, filter by character or all characters, open
  archived Details, rename sessions and delete them after confirmation. New titles
  suggest the starting area, local date and time; Finish lets you edit that title.
- Compare two saved sessions side by side across hourly XP, Gold, honor and every
  faction present in either session. The greater rate is gold, with a green
  triangle and percentage advantage when a valid opposing baseline exists.
- Keep each reputation faction's gains and tracked time when changing the watched
  faction during a session. Selecting None stops only reputation capture.
- Choose Focused, Extended or Full dashboard layouts, reorder metrics and enable
  XP and reputation milestone estimates independently, including both together.

## Changed

- Rebuild Session Details around a fixed summary card and separate Income,
  Expenses and Reputation tabs. Gold rows group retained items or money sources,
  show quantities and recorded valuations, and keep each flow's sum and table
  headings fixed while its rows scroll.
- Use a compact Compare panel with larger readings, gold session headings and a
  centered `vs.`. Rates show explicit spaced units: `xp/h`, `g/h`, `hon/h` and
  `rep/h`. The table compares rates; session duration remains contextual metadata.
  Value tooltips contain the inverse minute rate and total. Ties and zero/missing
  opposing baselines have no percentage; unavailable readings display zero with
  their metric unit.
- Keep History sessions on single rows with inline Rename, Details and Delete
  actions. Standard windows share native stacking, initial cascade placement and
  screen fitting. Session popups use centered larger text and shared title input.
- Offer History, Current Session and a separate Finish Session button in Sessions.
  The menu and current Details footer share the same confirmation and title editor;
  Cancel, X and Escape discard the draft without finishing or renaming the session.
  Confirmation is bound to the current session ID, so a stale dialog cannot finish
  a replacement session.
- Display numeric Gold rates and native coin totals. Dashboard metric tooltips show
  the total and the opposite rate period; full recorded accounting stays available
  in Details. Dashboard estimates use the same shared session and respect pauses.
- On normal logout/login, restore the current session paused without archiving it.
  A verified reload restores its previous state; offline, loading and verification
  time are excluded. Uncertain continuity stays paused with partial coverage.
- Freeze Gold at Finish with the prices and evidence available at confirmation.
  Unresolved values are excluded and marked incomplete; later responses cannot
  change the archived result or carry those movements into another session.

## Fixed

- Combine the first name and surname returned by Forever when labeling characters,
  and omit the realm separator when the client returns an empty realm.

## Compatibility and limitations

- Targets WoW Forever 1.60.1, Interface `16001`, with Lua 5.1. Optional TSM and
  Auctionator pricing and the standard minimap/broker launcher remain supported.
- This is a fresh session/settings model: pre-revamp tracker sessions and
  preferences are not imported. No saved-data or settings migration is introduced.
- History retains 100 summaries per character, details for the latest 20 and up to
  1,000 consultable Gold events per session. Tab sums cover retained known events,
  so they may differ from the complete session totals. These display limits do
  not truncate active accounting.
- Item pricing remains estimated farming value. Mail, transfers, purchases and
  vendor-sale receipts stay outside the recorded income/expense boundaries.

## Validation

- Automated: 1,392 simulation checks passed with actual Lua 5.1 through Python's
  `lupa.lua51` runner, covering the shared lifecycle and recovery, Gold accounting,
  grouped Details, saved history, comparison calculations, title validation,
  independent estimates, native menu contracts and virtualized scrolling.
- Local package: `per-hour-2.0.0-forever.zip` checked for its `per-hour/` root,
  TOC version and Interface, exact-case nested TOC/XML load references, source
  contents, embedded libraries and licenses, and excluded development files.
  All 60 packaged files match the source; 49 load references resolve with exact
  casing. All packaged Lua sources compile with Lua 5.1 and XML sources parse.
- Screenshots from in-game iteration informed the interface changes, but a full
  final-candidate gameplay check has not been established. Confirm the final
  Sessions button and dialogs, long session/faction labels, Compare alignment,
  percentages and scrolling, all Gold/Reputation tabs, layouts and estimates,
  minimap access, reload/logout continuity and optional pricing addons in game.
  Simulation results do not establish native rendering or gameplay compatibility.
