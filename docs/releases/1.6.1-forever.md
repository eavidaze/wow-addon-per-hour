# 1.6.1-forever

Restore reliable access to Settings and trackers, improve minimap organizer
compatibility, and correct the valuation of poor-quality items.

Changes are compared with [v1.6.0](https://github.com/eavidaze/wow-addon-per-hour/releases/tag/v1.6.0),
the previous published Forever release. The release title and tag are `v1.6.1`.

## Fixed

- Replace the custom minimap button with a standard LibDataBroker/LibDBIcon
  launcher to address the custom-button warning and missing click actions with
  minimap organizers such as Leatrix Plus. This addresses
  [issue #16](https://github.com/eavidaze/wow-addon-per-hour/issues/16).
  The required libraries are included; no separate installation is needed.
- Make `/perhour` open Settings directly, including when the minimap icon is
  hidden. Right-clicking the minimap icon continues to open the same panel.
- Always value poor (gray, quality 0) items at their vendor sell price without
  querying TSM or Auctionator, including when pending native data arrives.
  Gray items with no vendor value contribute nothing. Existing recorded prices
  remain unchanged.

## Changed

- Use `/perhour xp`, `/perhour gold`, `/perhour honor` or `/perhour rep` to show
  the corresponding tracker. Repeating a command keeps the tracker visible;
  it does not start, resume or reset the session or hide other trackers.
- Use `/perhour help` for descriptions of all commands. Unknown commands point
  to help; `/perhour` alone opens Settings, with no `settings` subcommand.
- Show native item rarity colors on names in Gold Details. Loading placeholders
  and non-item events use normal text, including when rows are reused.
- Anchor the tracker menu to the clicked launcher so a visible broker display
  remains usable while the minimap icon is hidden. LibDBIcon controls native
  dragging and minimap-shape placement; the existing per-character position
  setting remains in its original format.

## Compatibility and limitations

- Targets WoW Forever 1.60.1, Interface `16001`.
- No saved-data or settings migration is introduced. Gold retains previously
  recorded transaction prices and its existing accounting boundaries.
- Minimap organizer interaction, native menus, tooltip rendering and item
  quality colors still require actual in-game validation with WoW Forever.

## Validation

- Automated: 2,997 simulation checks passed with Lua 5.1 through Python's
  `lupa.lua51` runner, including standard icon registration, broker metadata,
  hidden-minimap access, all text commands, native drag handling, saved positions,
  gray-item pricing and pending settlement, alongside existing tracker checks.
- Local package: `per-hour-1.6.1-forever.zip` checked for its `per-hour/` root,
  matching TOC version and Interface, exact-case TOC/XML load references,
  source-file contents, embedded libraries and license notices, and excluded
  development files.
- In-game validation remains pending. Test Leatrix's minimap enhancements,
  both icon clicks, dragging on round and square minimaps, broker displays,
  `/reload`, character changes, slash commands and Gold Details rendering.
  Simulation results do not establish gameplay compatibility.
